You own the machine.

Zana is an open-hardware line for the physical world — robot mowers, sensor nodes, security and cleaning bots, cameras. Download the CAD and PCB, build it, or run a finished unit. Every design drops straight into Aql, the open command center — but they are vendor-neutral and yours to change.
